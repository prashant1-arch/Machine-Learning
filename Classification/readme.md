# 🎓 Student Pass/Fail Classification Model

A Machine Learning project that predicts whether a student will **Pass or Fail** based on study hours, attendance, and previous marks using Logistic Regression.

## 📌 Project Overview

This project uses a Logistic Regression classification algorithm to predict student academic performance.

The model analyzes three important factors:
- Study Hours
- Attendance
- Previous Marks

Based on these inputs, it predicts whether a student is likely to Pass or Fail.

## 🚀 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab / Jupyter Notebook

## 📊 Dataset Description

The dataset contains the following features:

| Feature | Description |
|---|---|
| Study_Hours | Hours spent studying |
| Attendence | Student attendance percentage |
| Previous_Marks | Previous examination marks |
| Result | Pass or Fail (Target) |

## ⚙️ Machine Learning Workflow

1. Import required Python libraries.
2. Create and understand the dataset.
3. Perform data analysis.
4. Check missing and duplicate values.
5. Visualize the dataset.
6. Split data into training and testing sets.
7. Train the Logistic Regression model.

9. Evaluate model performance.
10. Predict results for new students.

## 🧠 Algorithm Used

**Logistic Regression**

Logistic Regression is a supervised machine learning algorithm used for classification problems.

It predicts whether a student belongs to the Pass or Fail category.
